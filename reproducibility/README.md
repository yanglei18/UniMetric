# Reproducing Metric-Depth experiments

The published matrix has 12 datasets × 9 depth models plus one default YAML
per dataset (120 production YAMLs). Algorithmic YAML values were preserved
during consolidation; comments were added, and 123 path-only fields in the
retained YAMLs were corrected or isolated for the original runtime. The
relative source/config hashes in `source-and-config-manifest.json` identify the
public project files. `freeze_manifest.py --include-vendor` can separately
record a local ignored vendor cache for an exact-machine audit.

## 1. Environment and third-party code

Use Python 3.11. Install PyTorch/torchvision for your CUDA driver, then the
tested base package versions in `../requirements-base.txt`. The old-server
package snapshot is in `env/QWen-pip-versions.txt` and
`env/QWen-conda-explicit.txt`; it is a reference, not a portable one-command
environment installer. Install SAM2 and the chosen depth model from their
upstream repositories, respecting separate source and checkpoint licenses.
The local development-server `vendor/` cache is ignored by Git; see
[`../vendor/README.md`](../vendor/README.md) for links and licensing notes.

## 2. Paths, inputs, and API credentials

Datasets and weights are not in this repository. Make a local YAML copy and
remap environment-specific paths without altering model/scale settings:

| YAML field | Required input/output |
| --- | --- |
| `runtime.data_path` | Dataset frames, calibration and evaluation ground truth |
| `models.*_project_root` / `models.*_checkpoint` / `models.*_weights` | Selected model's upstream code and licensed checkpoint |
| `paths.sam_checkpoint` / `paths.sam_config` | SAM2 checkpoint and package config |
| `depth.long_temp_root` | Writable temporary storage for long-sequence inference |
| `paths.output_root` / `paths.p3_images` | Writable, isolated results and P3-image locations |

The machine-local `external-assets-manifest.json` is generated by
`freeze_external_assets.py` and excluded from the public Git index because it
contains absolute server paths. It records hashes for directly named model
files. One verified reference is `lingbot-map-long.pt` with SHA-256
`832bc82cbae0bc9bbe946ef5ee1f7226abd8c0e183ccf8beddbb3d133576f409`.

Set `DOUBAO_API_KEY` for Doubao configs. Humanoid Everyday's Qwen API configs
need `MODEL_KEY` and `BASE_URL` (optionally `MODEL_NAME`). Never store key values
in a YAML, log, or Git commit.

## 3. Validate and run

```bash
python reproducibility/check_setup.py
python reproducibility/test_active_features.py
python reproducibility/test_prompts.py
python reproducibility/test_supported_models.py
python -m pytest -q tests/test_omega_balanced_preprocess.py tests/test_omega_dataset_intrinsics.py
```

For a smoke test, copy the desired YAML outside `configs/`, set
`runtime.all_sequences: false`, `runtime.sequence_name: [one_real_sequence]`,
`runtime.frame_count: 10`, and `parallel.enable: false`, then run that copy.
Production runs use the unmodified model YAML after local path remapping:

```bash
python get_metric_scale.py --config /path/to/smoke.yaml --disable-parallel
python get_metric_scale.py --config configs/jrdb/pi3_long.yaml
```

The normal pipeline mines VLM anchors, creates SAM masks, prepares P3 images,
predicts depth, estimates scale and saves metrics. `depth_only: true` requires
existing VLM JSON and intentionally skips scale/metrics.
`cleanup_depth_outputs_after_metrics: true` removes the current model's depth
intermediates after metrics, not VLM/SAM caches. Cross-run reuse is off by
default; set `runtime.resume_existing_results: true` only if code, YAML,
dataset and cache provenance are identical.

## 4. Preserved behavior and limitations

- VGGT-Omega retains `balanced` preprocessing and dataset intrinsics for 3EED.
- JRDB per-sequence anchor overrides are applied at the scale stage.
- Argoverse's explicit prompt forwards the historical `default.py` driving
  prompts; four task texts are tested for exact equality.
- CEAR/Humanoid Scal3R offload, FusionPortable plane-mask fallback, V2X Radar
  camera-translation/dynamic-anchor options, and Humanoid Qwen/hard-sequence
  behavior are retained.

On the original validation host, all 120 YAMLs parsed, 18 overrides and 281
configured prompt routes passed checks, and six Omega tests passed. Full GPU
metrics were **not** re-run: PyTorch could not initialize CUDA there, and the
validation shell had no VLM API credentials. API responses may also vary over
time; static checks alone do not prove identical final metrics. Licensing of
first-party code is pending rights-holder confirmation; see
[`../LICENSING.md`](../LICENSING.md).
